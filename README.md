# News Reader

A lightweight vanilla JavaScript news headline aggregator consuming public news feeds.

## Features

- **Category Filtering:** Filter global headlines by technology, business, science, sports, and entertainment.
- **Direct Source Links:** Clean card previews with original publication timestamps and publisher metadata.
- **Fast Rendering:** Direct DOM templating with zero client-side framework overhead.

## Tech Stack

- Vanilla JavaScript (Fetch API)
- NewsAPI REST Endpoints
- HTML5 & CSS3
